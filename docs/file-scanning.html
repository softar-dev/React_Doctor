🚀 Core Module: File Scanner

This module is the entry point for the ReactDoctor Static Analyzer. It is designed to be cross-platform (Linux/Windows) and recursive.

📦 Required Packages

Run these commands in the /core directory:

# Main dependency for file pattern matching
npm install glob

# Type definitions for Node.js (Fixes 'process' and 'path' errors)
npm install -D @types/node

# Engine to run TypeScript files directly
npm install -D ts-node

📂 Current Architecture

File Responsibility
scanner.ts Uses glob to find .ts, .tsx, .js, .jsx files while ignoring node_modules.
test-scanner.ts A debug utility to verify the scanner is hitting the right directories.

🖥️ Cross-Platform Compatibility

For AI Assistants: The code uses path.resolve() and a regex .replace(/\\/g, '/') to ensure that Windows backslashes are converted to forward slashes before being passed to glob. This prevents the scanner from returning empty results on Windows machines.

🛠️ How to Test

To run the scanner and see the found files in the terminal, use the following command:

Linux/Mac:

npx ts-node --compiler-options '{"module":"commonjs"}' src/test-scanner.ts

Windows (PowerShell):

npx ts-node --compiler-options '{\"module\":\"commonjs\"}' src/test-scanner.ts

📝 Reference for AI Assistance

"The current implementation uses CommonJS modules. The scanner identifies files recursively using the glob pattern **/*.{ts,tsx,js,jsx}. It is configured to ignore node_modules, dist, and build to optimize performance. Ensure any future AST Parser modules receive absolute paths from this scanner."
